# Raw Spatial Data Sources

This directory documents the raw source boundaries and references used to generate the Sri Lanka DSD master spatial table (`data/reference/sri_lanka_dsd_reference.csv`).

## Data Source
- **Dataset:** Sri Lanka - Subnational Administrative Boundaries (COD-AB)
- **Publisher:** Survey Department of Sri Lanka & United Nations OCHA
- **Format:** Geodatabase / Shapefile / Excel
- **HDX Resource URL:** [Humanitarian Data Exchange (HDX) Sri Lanka Boundaries](https://data.humdata.org/dataset/cod-ab-lka)
- **License:** Creative Commons Attribution for Intergovernmental Organisations (CC BY-IGO)

To re-download the original Excel dataset if needed:
```bash
curl -L -o data/raw/lka_admin_boundaries.xlsx "https://data.humdata.org/dataset/0bedcaf3-88cd-4591-b9d5-5d3220e26abf/resource/89f5e8ba-4385-48ad-a328-2006ab717ab3/download/lka_admin_boundaries.xlsx"
```
